# Android Application Development Internship

## About

This repository contains the Android application projects completed during
the AICTE–EduSkills Virtual Internship Program in the Google Android
Developer domain.

The projects were developed using Kotlin, Android Studio, and Jetpack
Compose as part of the Android Basics with Compose course.

## Projects

### 1. Business Card
A simple Android application that displays personal information using
Jetpack Compose layouts.

### 2. Art Space
An Android application that displays three artworks along with their
related information.

### 3. 30 Days Fitness
A fitness-themed application presenting activities for a 30-day period
using a scrollable interface.

### 4. My City
An application that presents places in a city, including restaurants,
coffee shops, and parks.

### 5. BookShelf
An application that displays information about four books.

### 6. Flight Search
An application for searching and displaying flight-related information.

## Technologies Used

- Kotlin
- Android Studio
- Jetpack Compose
- Android SDK
- Gradle
